# ExpoRedCrObot (Field-Ready Edition 🏆)

โปรเจกต์นี้คือเวอร์ชันสมบูรณ์ที่สุดสำหรับหุ่นยนต์คัดแยกพลอย 6 สี (ExpoRedCrObot) โดยถูกออกแบบมาให้ **"พร้อมแข่ง (Field-Ready)"** และทนทานต่อสภาพแวดล้อมหน้างานจริง (แสงเปลี่ยน, เงาบัง, อินเทอร์เน็ตหลุด)

ไฟล์หลักที่ใช้รันโปรแกรมคือ: **`Field_Ready_Project/Final1.py`**

---

## ✨ ฟีเจอร์เด่นของเวอร์ชันนี้ (Hybrid AI + CV)

1. **AI Object Detection (Roboflow):** 
   - ใช้ AI เป็นสมองหลักในการหาตำแหน่ง "เพชร" บนสนาม ช่วยกรองสิ่งรบกวน เช่น แสงสะท้อน, รองเท้าคน, หรือสีบนตัวหุ่นยนต์ทิ้งไปได้อย่างชาญฉลาด
   - แสดงผล UI แบบ Bounding Box พรีเมียม (บอกสีและความแม่นยำ)
2. **ระบบตาสำรองฉุกเฉิน (CV Fallback):**
   - หากอินเทอร์เน็ตหน้างานหลุด หรือ Cloud API มีปัญหา หุ่นยนต์จะ **ไม่หยุดเดิน** แต่จะสลับไปใช้ระบบแยกสีดั้งเดิม (HSV) ทันทีแบบไร้รอยต่อ
3. **วงกลมบาเรียลบจุดบอด (Robot Exclusion Zone):**
   - รัศมีปกป้องตัวหุ่น 130 พิกเซล ป้องกันไม่ให้ AI สับสนและมองหุ่นยนต์ตัวเองเป็นเพชร
4. **แก้ปัญหาสีเพี้ยน (Smart Twin Resolver):**
   - หากกล้องแยกสีฟ้า (Cyan) และน้ำเงิน (Blue) ไม่ออกตอน Setup โค้ดจะฉลาดพอที่จะเติมสีที่ขาดให้อัตโนมัติ ทำให้แข่งต่อได้ทันที
5. **เร่งแสงด้วยซอฟต์แวร์ (Digital Gain):**
   - หากใช้กล้อง Webcam ที่ล็อกค่าแสง (Hardware Exposure) โค้ดจะปรับไปใช้การคูณค่าความสว่างพิกเซลแทน ทำให้กดเพิ่ม/ลดแสงได้ทุกกล้อง 100%
6. **รองรับกล้องมือถือ (IP Webcam):**
   - สามารถใช้มือถือ Android เป็นกล้องมุมสูงได้ง่ายๆ ผ่าน Wi-Fi โดยใส่ลิงก์ IP Address ลงไป

## 🚀 วิธีการใช้งาน (How to Run)

เปิด Terminal ใน VSCode แล้วพิมพ์คำสั่ง:
```bash
cd Field_Ready_Project
python3 Final1.py
```
*(หากต้องการใช้กล้องมือถือ ให้รัน: `python3 Final1.py --camera-index http://192.168.x.x:8080/video`)*

### ขั้นตอนการ Setup ก่อนเริ่ม (ทำแค่ครั้งแรก)
1. **STEP 1:** คลิกเลือกมุมสนามทั้ง 4 มุม (ซ้ายบน, ขวาบน, ขวาล่าง, ซ้ายล่าง) เพื่อให้กล้องดัดภาพเป็นมุมมอง Top-down (Homography)
2. **STEP 2:** คลิกเลือกใจกลางจุดปล่อย (Drop Zones) ทั้ง 6 สีให้ครบ
3. **READY:** วางหุ่นยนต์ลงสนาม (รอให้เป้ากากบาทสีเขียว ArUco ขึ้นบนตัวหุ่น) แล้วกดปุ่ม `Spacebar` เพื่อลุย!

## ⌨️ คีย์ลัดควบคุม (Hotkeys)

- `Spacebar` : เริ่ม / หยุด โหมด Auto (คัดแยกเพชรอัตโนมัติ)
- `[` และ `]` : ลด / เพิ่ม ความสว่างของกล้อง
- `Q` : ปิดโปรแกรม (Quit)
- `R` : รีเซ็ตมุมสนามใหม่ทั้งหมด (Reset Field)
- `Z` : รีเซ็ตเฉพาะจุดวงกลมสี 6 จุด (Remap Zones)
- `M` : สลับโหมดขับมือ (Manual Mode)
  - `W`, `A`, `S`, `D` : ขับหุ่นยนต์ด้วยมือ
  - `O` : กางที่คีบออก (Open)
  - `C` : หุบที่คีบ (Close)
